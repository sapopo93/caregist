## Step 2 — rating-source resolver

`api/services/rating_resolver.py`. Evidence comes from the API, the ratings file (with inherited flag, sha256 and edition) and optional dated CQC-page observations. The resolver returns one of four statuses:

- `current`: the newest published value
- `inherited`: published before this registration, or flagged inherited
- `unresolved`: an undated or same-date conflict, or an inherited value contradicted by one earned under this registration. These are never shown.
- `none`: no published rating

Frozen fixtures `tests/fixtures/rating_audit_2026_10_22.json` were built by `artifacts/report-readiness/2026-10-24/build_rating_fixtures.py` from the audit packet, the ODS inherited flags and registration dates read from the database.

|---|---|
| 20 file-backed | file value, date, sha256 and edition retained. 19 `current`; Tillingham `inherited` (file flag Y; predates its 2023 registration) |
| 5 conflicts | St Stephens, Althorp Grange, Chesser → `current` Requires improvement from the newer file (older API value cannot override). Irchester 170 and Check House → `unresolved`, omitted. |
| 5 unrated | `none`; the "Inspected but not rated" sentinel is kept in evidence but never chosen |

Review: `artifacts/reviews/2026-10-25-pr127-fifth/REVIEW.md` (main checkout). F1/F2 and every earlier finding were rechecked as fixed. One new P2 remained.

**G1: a page flag about an older publication changed the status of a newer one.** Example: file Requires improvement 2025 marked inherited, API 2024, page 2024 marked not inherited. The newer inherited 2025 rating was shown as current in the narrative, PDF, CSV and JSON. The reverse case wrongly held back a newer earned rating.

- a page flag counts only when the page states the same publication date;
- an undated "inherited" is applied conservatively;
- an undated "not inherited" clears nothing;

One earlier test changed meaning. `test_f1_later_explicit_false_clears_inheritance` relied on an undated "not inherited" clearing an explicit flag. It is now `test_f1_later_explicit_false_for_the_same_publication_clears_inheritance` (dated, same publication).
